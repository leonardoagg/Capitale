# M2 — Interfaccia e navigazione

## Implementazione

- Interfaccia mobile-first Dark finanziaria con token di colore, safe area iOS, barra inferiore persistente, focus visibile e supporto `prefers-reduced-motion`.
- Navigazione locale tra Home, Patrimonio, Movimenti e Analisi; Impostazioni accessibile dalla Home e con ritorno esplicito.
- Stati vuoti trasparenti: nessun valore patrimoniale, grafico, rendimento o dato dimostrativo è inventato.
- Il controllo occhio è già operativo per la riservatezza visiva degli importi mostrati; non è una misura di sicurezza o cifratura.

## Verifica browser desktop locale

Il 2026-11-27 sono state aperte e controllate nel browser locale Home, Patrimonio, Movimenti, Analisi e Impostazioni. Sono state verificate le etichette accessibili dei controlli e gli stati espliciti delle funzioni che saranno realizzate nelle milestone successive.
